## About The Project 

EduXAI is an AI-based educational helper for Children designed to support children in the 
basic subjects (mathematics, science, Arabic language, and English language). It offers
individualized and flexible experience in learning and understanding the lessons. The child
will have several options for the learning strategies (flip the cards, multiple-choice questions, 
and match the answer) for learning a new lesson. Also, the child can ask about the basic 
subjects, and EduXAI will explain them simply for him/her.
